# JavaScript: Zero to Warrior

The code for **JavaScript: Zero to Warrior**, a free JavaScript course for beginners from
[The Code Warrior](https://www.youtube.com/@askthecodewarrior) on YouTube.

Full course playlist: https://www.youtube.com/playlist?list=PLPyBpER1_WP8
Projects playlist: https://www.youtube.com/playlist?list=PLPJxFS6XIDbk

## How to use it
Each lesson has its own folder under `lessons/`:
- `solution/` is the project from the video.
- `starter/` is the "your turn" exercise, with TODOs for you to fill in.
- `README.md` sums up the lesson and gives you a few practice problems.

Watch the video first, then try `starter/` on your own before you open `solution/`.

Every lesson is a small [Vite](https://vite.dev) project. To run one, open its folder in VS Code, open a terminal, and type:
```
npm install
npm run dev
```
Then open the `Local:` link it prints. A lesson that runs in the terminal instead says so in its README (`node <file>.js`).
If you don't have Node.js and VS Code yet, lesson 01 shows you where to get them.
