# Lesson 01 starter: make the js-course project

This lesson's "your turn" is the setup itself: there's no code to fill in yet. Work through the TODOs in order,
in VS Code's terminal (Terminal → New Terminal). Every command is the same on Windows and on a Mac.

- [ ] TODO 1: check your tools: `node --version` and `npm --version` (Node 20.19+ or 22.12+; the LTS is best)
- [ ] TODO 2: go to your Desktop: `cd Desktop` (Windows with OneDrive backing up your Desktop: `cd OneDrive/Desktop`)
- [ ] TODO 3: make the project: `npm create vite@latest js-course -- --template vanilla`
      (answer `y` to "Ok to proceed?", then pick **No** for "Install with npm and start now?")
- [ ] TODO 4: `cd js-course`, then `npm install`
- [ ] TODO 5: File → Open Folder → Desktop → js-course → Open (Trust Folder & Continue if VS Code asks)
- [ ] TODO 6: `npm run dev`, then Command-click (Windows: Control-click) the `Local:` link
- [ ] TODO 7: in Chrome, open the Console: Command Option J (Windows: Control Shift J), and type `2 + 2`

When you're done, your page looks like the one in the video, and the Console answers `4`.
The finished project is in `../solution/`.
