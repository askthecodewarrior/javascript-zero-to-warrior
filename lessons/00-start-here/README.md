# Lesson 00: How to Learn JavaScript in 2027: Free Roadmap (Start Here)

Part of **JavaScript: Zero to Warrior**, a free JavaScript course for beginners.
Video: coming soon · Full course: https://www.youtube.com/playlist?list=PLPyBpER1_WP8

## What's in this lesson
- The roadmap: 48 lessons after this one, in two seasons. Season 1 (lessons 0-32) is JavaScript for Beginners, from
  variables to fetch and a weather app. Season 2 (lessons 33-48) is Intermediate JavaScript and Real Projects, and it
  ends with "All the JavaScript You Need Before React".
- Seven projects: a number guessing game, a calculator, a to-do list, a weather app, a portfolio website, a dashboard
  and a shopping cart.
- JavaScript runs in every major web browser, and with Node.js it runs outside the browser too.
- The tiny page from the video: a heading and a button. When you click the button, JavaScript changes the heading and
  writes `The button was clicked` in Chrome's console. You don't need to understand the code yet: lessons 21 to 23
  teach `querySelector`, `textContent` and `addEventListener`.

## Files
- `solution/`: the page from the video (a Vite project).
- `starter/`: the same page, with TODOs for making it your own.

## Run it
Lesson 1 sets up VS Code, Node.js and Chrome. Then open `solution/` (or `starter/`) in VS Code, open a terminal, and
type:
```
npm install
npm run dev
```
Then open the `Local:` link it prints: Command-click it on a Mac, or Control-click it on Windows. To see the console,
open Chrome's developer tools with Command Option J on a Mac, or Control Shift J on Windows.

## Practice
1. In `starter/`, do the three TODOs: change the heading's greeting, what it says after a click, and the console
   message. Save the file and watch the page update.
2. Open the console and click the button three times. How many lines does the console show? Look at the small number
   next to the message: Chrome groups the same message into one line with a count.
3. Click in the console, type `2 + 2` and hit Enter. What does it show? Try `'Hello, ' + 'warrior'` too.
